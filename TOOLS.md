# ChainScout Catalog — First 12 Tools (Beginner Focus)

Все описания написаны простым языком. Для новичков из Африки, Индии, Юго-Восточной Азии.

---

### 1. ChatGPT (OpenAI)
**Для чего:** Объяснить любую монету простыми словами, сделать чек-лист рисков, суммировать новости.
**Как использовать за 1 минуту:**  
Скопируй этот промпт:  
«Объясни [название монеты] как новичку. Что это, зачем нужно, главные риски, стоит ли изучать дальше. Максимум 8 предложений.»
**Цена:** Бесплатно (есть лимиты) / Plus
**Ссылка:** https://chatgpt.com

### 2. Claude (Anthropic)
**Для чего:** Длинные тексты, whitepaper, риски. Очень хорошо структурирует.
**Промпт:**  
«Сделай простой чек-лист рисков для [монета]. Включи: кто контролирует, ликвидность, разлок токенов, команда.»
**Цена:** Бесплатно / Pro
**Ссылка:** https://claude.ai

### 3. Grok (xAI)
**Для чего:** Быстрые новости + реальное время из X (Twitter). Хорош для «что сейчас происходит».
**Промпт:**  
«Что сейчас говорят про [монета] в крипте? Кратко и по делу для новичка.»
**Цена:** Бесплатно (с лимитами) / Premium
**Ссылка:** https://x.com/i/grok или grok.x.ai

### 4. CoinGecko
**Для чего:** Цена, капитализация, объём, простой обзор монеты.
**Как использовать:** Найди монету → смотри «Market Data» и «About».
**Цена:** Полностью бесплатно
**Ссылка:** https://www.coingecko.com

### 5. DeFiLlama
**Для чего:** Сколько реальных денег лежит в DeFi-проектах (TVL). Помогает понять, живой ли проект.
**Как использовать:** Ищи протокол → смотри TVL и изменение за 7/30 дней.
**Цена:** Бесплатно
**Ссылка:** https://defillama.com

### 6. TradingView
**Для чего:** Графики цены. Можно смотреть простые индикаторы (RSI, MA).
**Как использовать:** Открой график BTC или любой монеты → добавь RSI.
**Цена:** Бесплатный план достаточный для старта
**Ссылка:** https://www.tradingview.com

### 7. Arkham Intelligence
**Для чего:** Посмотреть, куда большие кошельки (киты) переводят деньги.
**Как использовать:** Введи адрес или название монеты → смотри потоки.
**Цена:** Есть бесплатный уровень
**Ссылка:** https://www.arkhamintelligence.com

### 8. LunarCrush
**Для чего:** Насколько монета «шумит» в соцсетях (Twitter, Reddit и т.д.).
**Как использовать:** Найди монету → смотри Social Score и Galaxy Score.
**Цена:** Бесплатный уровень есть
**Ссылка:** https://lunarcrush.com

### 9. ChainGPT
**Для чего:** ИИ, который специально обучен на крипте и блокчейне.
**Как использовать:** Задавай вопросы про смарт-контракты, токеномику, проекты.
**Цена:** Есть бесплатные кредиты
**Ссылка:** https://www.chaingpt.org

### 10. Token Metrics
**Для чего:** AI-оценки монет и простые сигналы.
**Как использовать:** Смотри AI Rating и Trader Grade.
**Цена:** Есть free-доступ
**Ссылка:** https://tokenmetrics.com

### 11. Messari
**Для чего:** Качественные обзоры проектов и фундаментальный анализ.
**Как использовать:** Ищи проект → читай Research или Overview.
**Цена:** Базовый доступ бесплатный / платный Pro
**Ссылка:** https://messari.io

### 12. Coinrule
**Для чего:** Создавать простые торговые правила и тестировать их без реальных денег (paper trading).
**Как использовать:** «Если цена BTC упала на 5% — купить» → тестируй.
**Цена:** Есть бесплатный план
**Ссылка:** https://coinrule.com

### 13. ChainGPT
**Для чего:** ИИ, специально обученный на крипте и блокчейне. Хорош для вопросов про смарт-контракты и проекты.
**Как использовать:** Задавай вопросы про токеномику, риски, новости.
**Цена:** Есть бесплатные кредиты
**Ссылка:** https://www.chaingpt.org

### 14. Token Metrics
**Для чего:** AI-оценки монет и простые рейтинги (Bullish / Bearish).
**Как использовать:** Смотри AI Rating и Trader Grade.
**Цена:** Есть free-доступ
**Ссылка:** https://tokenmetrics.com

### 15. CoinMarketCap AI (CMC AI)
**Для чего:** Быстрые ответы по любой монете на основе данных CoinMarketCap. Очень удобно для новичков.
**Как использовать:** Задай вопрос про монету прямо на сайте CMC.
**Цена:** Бесплатно (есть лимит кредитов)
**Ссылка:** https://coinmarketcap.com

---

**Принцип отбора:**  
Сначала бесплатные и простые → потом чуть более продвинутые.  
Никаких обещаний «лёгких денег». Только инструменты для быстрого понимания.
