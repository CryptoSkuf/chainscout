# ChainScout: Telegram-бот с каталогом ИИ-инструментов для анализа крипты

Бот на 5 языках (English, Français, Bahasa Indonesia, Tiếng Việt, Kiswahili) для аудитории Африки и Юго-Восточной Азии.
Он помогает подобрать инструмент под задачу (цены и графики, on-chain, новости и сентимент, ИИ-исследования, проверка на скам),
собирает подписчиков на советы и присылает владельцу отчёты.

Построен по схеме из видео: бот ведёт «агентный бизнес» сам, но **рассылки и спонсорские размещения уходят только после вашего подтверждения**.

## Что умеет бот

**Для пользователей**
- `/start`: выбор языка, приветствие и предупреждение «не финансовый совет»
- каталог по целям и общий список, карточка инструмента со ссылкой на сайт
- `/guides` и кнопка «Guides»: три гида (проверка токена на скам, основы on-chain данных, ИИ-инструменты без самообмана), листание страниц и кнопки на упомянутые инструменты
- подписка на советы (`/stop` отключает её)
- пометки «Ad» для спонсорских записей и раскрытие партнёрских ссылок

**Для владельца** (только Telegram ID из `ADMIN_IDS`)
- `/stats`: отчёт: пользователи, языки, подписчики, топ инструментов
- `/check`: проверка, что все ссылки каталога открываются
- `/draft <en|fr|id|vi|sw|all> <текст>`: черновик рассылки. Уходит только после нажатия «Отправить» и только подписавшимся
- `/approve_sponsor <id>` и `/revoke_sponsor <id>`: показать или скрыть спонсорскую запись

**Рутина (как «утренние задачи» из видео)**
- ежедневно в `ROUTINE_TIME_UTC`: проверка ссылок, при проблемах приходит сообщение
- по понедельникам в это же время: недельный отчёт

## Запуск

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. Узнайте свой Telegram ID у @userinfobot.
3. Установка и запуск:

```bash
pip install -r requirements.txt
cp .env.example .env        # впишите BOT_TOKEN и ADMIN_IDS
python test_smoke.py        # быстрая проверка без токена
python test_flow.py         # прогон по всем кнопкам на всех языках
python bot.py
```

Для постоянной работы разверните на любом VPS или хостинге (Railway, Fly.io, Hetzner и т. п.) под systemd/Docker.
Файл `state.json` хранит пользователей, поэтому он должен лежать на постоянном диске.

## Как зарабатывать

1. **Партнёрские ссылки.** В `catalog.json` впишите `affiliate_url` у нужного инструмента. Кнопка «Open website» поведёт по ней,
   а в карточке автоматически появится пометка о партнёрской ссылке.
2. **Спонсоры.** Добавьте запись с `"sponsor": true`. Пока вы не выполните `/approve_sponsor <id>`, её никто не видит.
3. Платёжный сервис для этого не нужен. В видео использовался Stripe, но боту достаточно партнёрских ссылок.
   Если понадобятся платные подписки, добавьте любую платёжную систему, доступную вам и вашим пользователям.

## Что нужно сделать до запуска

- **Проверить каталог.** Описания и ссылки написаны по общим знаниям и в поле `checked` стоит `null`.
  Откройте каждый сайт, убедитесь, что инструмент работает и описание верно, и поставьте дату в `checked` (например, `"2026-10-17"`).
  Бот напомнит о записях без свежей проверки в недельном отчёте.
- **Проверить юридическую сторону.** Правила рекламы и продвижения криптовалют сильно отличаются по странам Африки и ЮВА.
  Некоторые страны ограничивают такую рекламу. Бот не даёт сигналов и советов купить или продать, не обещает доходность.
  Не меняйте это, особенно для аудитории, у которой часто встречается скам.
- **Удалить лишнее.** Если в каталоге есть инструменты, которые вы не готовы рекомендовать, уберите их из `catalog.json`.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | логика бота, команды, рутина |
| `locales.py` | тексты интерфейса на 5 языках |
| `catalog.json` | каталог инструментов (id, категория, уровень, ссылки, описания на 5 языках) |
| `guides.py` | гиды на 5 языках: их читают и бот, и сайт |
| `site/` | сайт-каталог с гидами, см. `site/README-SITE.md` |
| `test_smoke.py` | проверка текстов, каталога, гидов и клавиатур без токена |
| `test_flow.py` | нажимает все кнопки бота на всех языках, проверяет лимиты Telegram |
| `devstubs.py` | заглушки, чтобы тесты шли и без установленных библиотек |
| `.env.example` | пример настроек |

## Идеи на следующий шаг (из видео)

- сайт-каталог с гидами уже собран в папке `site/`; он берёт данные из тех же `catalog.json` и `guides.py`;
- раздача трафика через X и Telegram-каналы на нужных языках;
- ИИ-агент, который сам ищет новые инструменты и предлагает вам добавить их в каталог. Публикацию по-прежнему подтверждаете вы.
