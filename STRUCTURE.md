# ChainScout — Structure of MVP (v0.1)

## Главная страница
- Заголовок: ChainScout — AI tools that help beginners understand crypto faster
- Короткое объяснение: «Мы собираем только простые и полезные ИИ-инструменты. Для тех, кто только начинает.»
- 4 быстрых раздела по задачам:
  1. Понять монету за 5 минут
  2. Проверить риски
  3. Посмотреть тренд и график
  4. Узнать, что сейчас обсуждают
- Кнопка «Смотреть все инструменты»
- Форма email: «Получать 1 полезный совет раз в неделю» (пока только сбор)

## Каталог
- Карточки инструментов
- Фильтры: Бесплатно / Для начинающих / Ончейн / Соцсети / Графики
- У каждой карточки:  
  - Название  
  - Для чего (1 предложение)  
  - Как использовать за 1 минуту  
  - Готовый промпт (если ИИ)  
  - Цена  
  - Ссылка

## Гайды (простые)
1. «Как за 10 минут проверить любую монету» (используя 3–4 инструмента)
2. «5 вопросов, которые нужно задать ИИ перед покупкой»
3. «Что такое TVL и зачем на него смотреть»

## SEO (первый слой)
Основные запросы:
- best free AI tools for crypto beginners
- how to analyse crypto with ChatGPT
- simple crypto research tools for beginners
- AI tools to understand cryptocurrency India / Africa / Southeast Asia
- crypto tools for beginners no experience

Позже добавим локальные языки (хинди, суахили, индонезийский и т.д.).

## Технический стек MVP
- Простой статический сайт (HTML + Tailwind или чистый CSS)
- Хостинг: Vercel (бесплатно)
- Форма email: пока Google Form или Resend (когда будет доступ)
- Позже: Next.js если нужно
