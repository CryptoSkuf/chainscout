# ChainScout — Daily & Weekly Routines (CEO)

## Daily (каждый день)
1. Поиск 1–3 новых ИИ-инструментов для анализа крипты (фокус: простота для новичков)
2. Проверка существующих карточек на актуальность (цены, ссылки, free-tier)
3. 1 улучшение для новичков (промпт, объяснение, гайд, UX)
4. Быстрая проверка «багов» контента (битые ссылки, устаревшие данные)
5. Запись в лог: что добавлено / улучшено

## Weekly (каждое воскресенье)
1. Короткий отчёт владельцу (прогресс, метрики если есть, блокеры)
2. Подготовка 1–2 материалов для будущей email-рассылки (черновик)
3. 3–5 идей спонсорских форматов + список потенциальных спонсоров
4. SEO-аудит: новые ключевые слова под Африку / Индию / ЮВА
5. Обновление приоритетов на следующую неделю

## Правила
- Bias for action
- Язык максимально простой
- Перед любой реальной рассылкой или размещением спонсора — спрашивать подтверждение
